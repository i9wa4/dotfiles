# 非公開 Gist の運用手順

## 1. 可視性と秘密情報

GitHub の `secret` Gist は公開一覧には出ないが、URLを知る人は閲覧できる。
アクセス制御された保管庫ではないため、トークン、秘密鍵、個人情報、未公開データを含むファイルをアップロードしない。
公開設定になった場合はURLを共有せず、削除してsecret Gistを作り直す。

## 2. 引き継ぎ

Postmanでは、Gist
URL（secretであることを確認済み）、元の`mkmd`パス、検証コマンドと結果、残課題を日本語で伝える。
Gist URLをissue、PR、公開ログへ転載しない。不要になったsecret Gistは削除する。

## 3. 失敗時

作成に失敗した場合はローカルの`mkmd`記録を正本として保持し、失敗理由と次の対応をPostmanへ報告する。外部公開を伴う操作は人間の明示的な承認なしに実行しない。
